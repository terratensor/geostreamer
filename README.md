# GeoStreamer

Утилита для потоковой обработки CSV файлов с именованными сущностями, обогащения их геоданными из Manticore Search и подготовки данных для загрузки обратно в Manticore.

## Возможности

- Поточное чтение больших CSV файлов (разделитель `|`)
- Пакетный поиск сущностей в Manticore Search с поддержкой multi-queries
- Агрегация уникальных геохешей (строковых и uint64) по `doc_id`
- Сохранение промежуточных результатов в NDJSON формате
- Чекпоинты для возобновления обработки с места остановки
- Подготовка bulk-файлов для загрузки в Manticore

## Архитектура

Проект следует принципам гексагональной архитектуры с четким разделением на domain, ports и adapters.

## Требования

- Go 1.25+
- Manticore Search (для работы с геоданными)
